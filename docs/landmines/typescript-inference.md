# TypeScript inference landmines

The full entries behind the **TypeScript inference** triggers in `AGENTS.md` § Landmine index, in the same order. Each one was written after someone paid for it. Read the entry for whatever surface you are about to touch before writing code; where an entry points on to `docs/ARCHITECTURE-NOTES.md`, `docs/EPIC-STATUS.md` or `docs/FOLLOWUPS.md`, follow it. When a change makes an entry wrong, fix it here in the same session — and update its trigger in `AGENTS.md` if the trigger itself moved.

- Writing TS a subagent cannot compile? Four inference shapes have shipped as build breaks — truthiness that never narrows a `string` union member, a spread whose index signature erased the concrete fields, a library constructor missing a required param, and a property narrowing lost inside a nested closure. They surface only in the owner's `type-check` — vitest does not type-check — and then fail the web image build, which blocks the gated `migrate` job. Detail + the fix for each in `AGENTS.md` § Code conventions.
